Thông Báo Gộp Server - 25/11

25/11/2024

Xin chào các Chủ Quán,

Để phục vụ trải nghiệm chơi game của Chủ Quán, sẽ tiến hành bảo trì từ 14h ngày 25/11/2024 nhằm gộp các server sau đây:

  • Server 10: Gộp từ server 10, 11, 12, 13.
  • Server 15: Gộp từ server 15, 16, 17, 20.
  • Server 22: Gộp từ server 22, 24, 25, 26.
  • Server 41: Gộp từ server 41, 42, 43.

Sau khi bảo trì xong, Chủ Quán sẽ được trải nghiệm chơi game mượt mà hơn với những người bạn mới! Cùng đón chờ nhé!

Lưu ý: Chỉ các server được gộp mới bảo trì, các server còn lại sẽ vẫn hoạt động bình thường. Dự kiến bảo trì trong vòng 1 tiếng 30 phút.
